Quick add

Type it the way you'd text it.

Press N anywhere and write chai 40 upi, uber 250 yesterday. Spence turns each entry into a card with the amount, place, category, date and account filled in. Fix anything with a click, press Enter, done.

  • Understands 1.2k, ₹499, 2.5L, "yesterday", "last sat", "12 nov"
  • Knows "got" is money in, "refund" is money back, and "monthly" is a bill
  • Works offline; the AI only helps with categories it can't work out

Savings pots

Goals that fill themselves a little.

Name a goal, set a date, and Spence tells you the pace you need, per month and per week. Then it finds money for it: the spare change from rounding up each purchase, what your budgets didn't use, a bonus for every no-spend day, and small challenges.

  • Linked transfers, like a monthly recurring deposit, count on their own
  • Challenges like "skip Dining for two weeks" or "5 no-spend days"
  • Nothing moves without your tap, so the numbers stay honest

Get started

Free, open and yours.

Spence is a small app you run on your own computer: a .NET API and a web app you open in your browser.

Run it

Needs the .NET 11 SDK and Node 24+.

# API
cd SpenceAI.WebApi
dotnet run          # http://localhost:5234

# Web app, in a second terminal
cd spence-ai-web
npm install
npm run dev         # http://localhost:5173

Pick your AI

OllamaRuns on your computer, fully offline. Nothing leaves your machine. Try qwen2.5:7b.
GeminiUse your own API key. Fast and accurate on long statements.
OpenAIUse your own API key.

Your key is encrypted on your computer. Summaries only ever send totals, never your transactions.

Not a developer? A one-click installer for Windows is planned: download, double-click, and Spence opens in your browser. Until then, setup needs the steps above.

Questions

Good to know

Does Spence connect to my bank?

No. You bring statements in yourself, as PDF, CSV or a photo. Spence never asks for a bank login and can't move money; savings pots and bills track money, they don't move it.

Where is my data stored?

In a single SQLite file in your user folder, with daily backups next to it. You can also copy each backup to a folder like OneDrive. Nothing is sent to us; there is no "us" server.

What does the AI see?

To read a statement, the statement's text goes to the AI you picked. With Ollama that never leaves your computer. Monthly summaries send only computed totals. Ask looks up only what your question needs (at most 25 rows at a time). Quick add sends only merchant names, and only when it can't work out the category itself.

Will it remind me about bills?

Yes, three ways: on the dashboard, from Sprig, and as browser notifications while Spence is open. Download the calendar file and your phone reminds you too, even when Spence is closed.

Which banks and currencies work?

Any statement that lists transactions, in any currency. Spence handles day-first and month-first dates, Indian number formats like 1,20,000, and credits marked Cr.
